After the Build

Security Controls Debrief

Every control below gets exercised on camera at least once — attacked first, then defended, in the case files above.

Port Security

MAC address limits with a violation shutdown, stopping CAM table floods before they force a switch to fail open.

SW2 / SW3 access ports

DHCP Snooping

Only the uplink to SW1 is trusted; every access port is rate-limited against DHCP starvation and rogue servers.

SW1

Dynamic ARP Inspection

Validates every ARP reply against the DHCP snooping binding table, closing the door on ARP spoofing.

SW1 · Internal VLAN

BPDU Guard + PortFast

Access ports come up instantly for hosts but shut down the moment they see a BPDU — no rogue switches, no STP games.

SW2 / SW3

DTP Disabled + Native VLAN

No port will negotiate a trunk, and the native VLAN is moved off the default — no double-tagged frame has anywhere to hop to.

All access ports

Extended ACL

Blocks the DMZ from initiating traffic into the Internal VLAN — the safety net even if a DMZ host is fully compromised.

R1, DMZ ↔ Internal

AAA + SSH

Locks down device management so the network gear itself isn't the easiest thing on the network to take over.
