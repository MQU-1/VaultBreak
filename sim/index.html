About these labs

Each lab is an approximation of a case-file chapter: a small topology, a set of attack buttons, and the exact security control that stops them.

Before / After

Every lab ships with a hardening toggle. Run the attack with it off, watch it land, then turn it on and watch the same move bounce off.

Nothing leaves the browser

No packets, no real servers. Attacks are simulated with plain JavaScript — opening a lab is completely safe.

Serve or ship

Run with any static server (python -m http.server 8000) or via the repo's nginx Docker image — labs are included.

Defense first

This project is educational. Every scenario ends with the control that stops the attack. Don't run any of it against systems you don't own.
